# observations/

走查过程中记录的**账号资产快照、操作流水、界面观察**等原始数据。区别于 `../docs/`（结构化报告），这里放的是**未加工的现场记录**。

## 什么放这里

- 测试账号在某时段的资产变化流水（订阅、赎回、余额）
- 页面数据抓拍（前后端字段值、接口返回、UI 显示）
- 时间序列的状态观察

## 什么**不放**这里

- 结构化审计报告 → `../docs/`
- 结构化用例 → `../testcases/`
- 缺陷记录 → `../bugs/`
- 人格 prompt → `../bots/`

## 命名

`YYYY-MM-DD-{主题}.{txt|md}`

- 例：`2026-08-13-subscribe-redeem-flow.txt`
- 例：`2026-08-13-asset-snapshot.txt`

## 现有记录

| 文件 | 内容 |
|---|---|
| [`2026-08-13-subscribe-redeem-flow.txt`](2026-08-13-subscribe-redeem-flow.txt) | 完整订阅→赎回→取消赎回→再订阅流程的时间戳与资产快照 |
| [`2026-08-13-asset-snapshot.txt`](2026-08-13-asset-snapshot.txt) | 单次资产快照，1000 USDT 订阅后的净值观察 |

## 脱敏

- 真实账号 UID / 邮箱 → 保留后 4 位或替换为角色代号
- 真实金额敏感时保留量级
- 涉及的机器人名如果是别人的公开机器人可保留，测试账户自建的用 `<bot_name>` 占位
