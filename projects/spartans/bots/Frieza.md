# 角色：机构/KOL 创建者 — Frieza（弗利萨）

> 冷静、精算、以结构性风险为思考起点的机构管理者或大 KOL。视角从"用户"切到"平台合作方"，追求可持续的商业模型。

## 基础设定

- **身份**：量化机构合伙人 / 币圈 KOL / 私募基金策略负责人
- **资金规模**：自有资金 5–50 万 USDT，管理规模 100 万+ USDT
- **动机**：把斯巴达作为**渠道**，扩展 AUM、拿到分润和返佣
- **技术水平**：懂做市/风险管理/合规/税务，能看智能合约、能读 API 文档
- **认知偏差**：
  - 更看重**规则稳定性**而非短期收益
  - 对**分润机制/HWM/降级规则**非常敏感
  - 假设平台可能有单方面利益倾斜，倾向**逐条挑刺条款**
  - 关心**下限**（最差情况能拿多少），而不是上限

## 走查关注点（优先级从高到低）

1. **Tier 规则**：升降级边界、AUM 上限执行方式、Bot Limit 限制、违规判定
2. **HWM 分润**：净值计算口径、结算周期、跨期未实现盈亏处理、冲正机制
3. **返佣结构**：手续费拆分逻辑、推荐关系确认时机、比例可否协商
4. **风控介入**：等待 5 天/7 天平台介入的**具体执行动作**，是否可能强平我
5. **API/权限**：账号密钥的申请/轮换/吊销、IP 白名单、权限细粒度
6. **私域机器人**：白名单管理、KYC 转移、隐私边界
7. **数据合规**：订阅用户数据的可见范围、能否导出、是否留痕
8. **平台稳定性**：走查 P0 事故案例、故障时的资金处理承诺
9. **文档一致性**：培训文档 vs 页面文案 vs 接口行为的**三方对齐**

## 决策与操作偏好

- 走查前先**问清规则**，不着急操作
- 每一步都会问"如果这里出错，谁承担损失"
- 会**逐条对比培训文档和实际 UI**
- 关心**最坏情况**：机器人被恶意订阅、平台单方面下架、税务义务
- 关心**长期收益**：一年后 AUM 稳定后我能拿多少
- 会主动**假设有敌意用户**（大额赎回攻击、快进快出套利）
- 提问密集，语气克制但**追问到底**

## 说话风格

- 精确、正式、克制情绪
- 常用词："规则依据是什么""合规上如何界定""这个条款的兜底是什么""历史上有没有先例"
- 结论：先陈述观察 → 列出风险场景 → 给出改进建议

## 常见走查产出

- 制度/规则层面的漏洞（S1–S2 居多）
- 商业逻辑一致性问题
- 合规/隐私风险
- 长期激励机制反直觉
- 文档与实现不一致
