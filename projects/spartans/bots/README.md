# bots/

斯巴达业务专用的**测试人格 prompt**。让 AI 带着不同的用户视角走查，覆盖单一视角容易遗漏的问题。

## 与其他目录的区别

- 这里放的是**人格定义**（身份、关注点、说话风格），不是数据
- 走查过程中记录的**账号资产快照/流水** → 放到 [`../observations/`](../observations/)
- 跨业务通用的角色片段 → 放到 `../../../ai-testlab/prompts/roles/`

## 现有人格

| 文件 | 角色 | 定位 | 主要走查方向 |
|---|---|---|---|
| [`Kakarotto.md`](Kakarotto.md) | 新手订阅者 | 小白散户 | 可读性、误操作、引导 |
| [`Vegeta.md`](Vegeta.md) | 激进短线玩家 | 资深 trader | 数据一致性、边界、成本 |
| [`Frieza.md`](Frieza.md) | 机构/KOL 创建者 | 平台合作方 | 规则风险、合规、长期激励 |

三个人格覆盖斯巴达的三类典型用户，形成**新手 / 高级用户 / 平台方**的三视角矩阵。

## 使用方法

**单人格走查**：

```
把 Kakarotto.md 内容作为 system prompt 加载
请求：请以 Kakarotto 视角走查斯巴达订阅流程，输出你遇到的困惑
```

**多人格对照**：

```
分别以 Kakarotto / Vegeta / Frieza 视角走查同一功能
对比三份产出，重叠部分 = 共性问题，差异部分 = 视角盲区
```

**用于用例生成**：

配合 `ai-testlab/skills/testcase-generator/` 使用，让不同人格各生成一批用例，扩大覆盖面。

## 新增人格

一个人格一个文件，遵循下面结构：

```markdown
# 角色：<定位一句话> — <代号>

## 基础设定
身份 / 资金规模 / 动机 / 技术水平 / 认知偏差

## 走查关注点
优先级排序的关注清单

## 决策与操作偏好
遇到情况的默认反应

## 说话风格
用词、句式、语气

## 常见走查产出
预期能发现的缺陷类型

## 触发这个人格
使用方式说明
```

## 命名

- **文件名 = 角色代号**（英文，首字母大写）
- 优先使用**辨识度高的代号**（虚构人物、动漫角色），避免用真实人名
