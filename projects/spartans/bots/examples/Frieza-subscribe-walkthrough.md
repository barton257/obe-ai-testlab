# Frieza 视角：订阅流程走查产出示例

> 人格：机构/KOL 创建者 / 走查功能：斯巴达订阅流程（从创建者角度审视） / 日期：2026-08-17

---

## 前提确认

在观察订阅流程前，我需要先确认几个结构性问题：

1. 用户订阅资金进入机器人合约账户后，我（创建者）能否看到实时余额？ → **能**，后台"账户"页签可见。
2. 用户赎回请求从哪个账户扣款？ → 资金账户（非合约账户），需要我手动从合约账户划转流动性。
3. 如果我不划转，平台何时介入？ → 培训文档：5 天提醒，7 天强制，但**具体执行条款页面不展示**。

→ **问题 F1**（S2）：7 天强制介入规则在开放平台说明页未展示，创建者注册前无法看到这个风险条款，属于信息不对称。

---

## 份额计算审计

用户 A 在净值 1.02 时订阅 1000 USDT，应获份额 = 1000 / 1.02 ≈ 980.39 份。

查看后台"用户"页签，该用户显示"订阅金额: 1000"，但**没有展示份额数量**。

→ **问题 F2**（S2）：后台用户列表只展示订阅金额，不展示份额数量，创建者无法验证份额铸造是否按当时净值正确计算。

---

## HWM 触发逻辑验证

当前净值 1.05，历史最高净值（上次分润时）1.03，未实现盈亏 +500 USDT。

按规则应触发可分润计算。查看后台"数据"页签，显示"预计下次利润分配: 0"。

→ **问题 F3**（S1）：当前净值 > HWM 且有已实现盈利，但控制台显示预计分润为 0，计算结果与规则不符，需排查 HWM 更新时机或结算接口逻辑。

---

## 风控规则一致性核查

培训文档写：赎回等待超 7 天平台可"强平仓位并自动赎回"。

开放平台申请页和机器人详情页均**未展示此条款**。

→ **问题 F4**（S2）：强制介入规则未在用户/创建者可见界面披露，合规风险——若平台据此强平，无法证明创建者事先知情同意。

---

## 私域机器人权限边界

创建私域机器人，白名单添加 UID-A。

测试未在白名单的 UID-B 直接访问 `/zh-cn/spartan-bot/{bot_name}` URL：

→ 页面**正常展示**机器人信息，只是订阅按钮变为"此机器人不对外开放"。

→ **问题 F5**（S2）：私域机器人的**绩效数据、持仓和历史订单**对未授权用户仍然可见，只隐藏了订阅入口。策略数据属于商业机密，应对非白名单用户完全隐藏。

---

## API 凭证安全

进入 API 页签，查看操作日志：**没有操作日志**。

→ **问题 F6**（S2）：API Key 的查看、复制、重置操作无审计日志，机构客户的合规要求（SOC 2 / 内部审计）无法满足。
