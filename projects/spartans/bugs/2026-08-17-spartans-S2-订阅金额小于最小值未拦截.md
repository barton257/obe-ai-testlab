# [S2] 订阅金额 0.5 USDT 未被拦截

- 环境：Testnet / API `bullapitest.1bullex.com`
- 复现率：1/1
- 提交人：Barton（AI 辅助）
- 日期：2026-08-17
- 影响接口：`POST /botapi/v1/invest/purchase`

## 复现步骤

```bash
curl -X POST 'https://bullapitest.1bullex.com/botapi/v1/invest/purchase' \
  -H 'authorization: Bearer <user1_token>' \
  -H 'content-type: application/json' \
  --data '{"userId":"10732164","botId":1342,"amount":0.5}'
```

## 预期

- 按 Tier 参数最小订阅金额为 1 USDT（`shared` 口径 / 运营配置）
- 应拒绝并返回 `{"code":1,"msg":"amount_below_min"}` 或类似业务错误

## 实际

- `{"code":0,"msg":"success","data":null,"timestamp":0}`
- `invest/history` 中出现 `tradeAmount=0.5, status=Init` 的记录

## 复现附件

见相邻用例 `tests/api/test_spartans_api.py::TestPurchaseErrorBranches::test_purchase_amount_zero_rejected`；下沉边界值 0.5 会命中此 bug。

## 备注

`amount=0` 会正确返回 `amount_not_allowed`，只有 `0 < amount < 1` 时穿透。疑似最小值校验用了 `> 0` 而非 `>= min_subscribe`。
