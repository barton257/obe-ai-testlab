# conventions/

跨业务的规则约定。修改这里的文件会影响所有业务，须由人工发起。

## 已有

- [`dod.md`](dod.md) — Definition of Done：功能上线前必查清单，覆盖测试金字塔、非功能维度、灰度回滚

## 建议清单

- `testcase-naming.md` — 用例命名详细规则和例外情况
- `priority.md` — P0–P3 判定标准
- `bug-severity.md` — S1–S4 严重级别定义和处理时限
- `commit-message.md` — Commit message 规范（含 `[AI-assisted]` 使用场景）
- `review-checklist.md` — PR / commit 审核清单

## 与 AGENTS.md 的关系

`../../AGENTS.md` 是**总纲**，本目录是**细则**。冲突时以 AGENTS.md 为准。
